# Caesar Cipher in Python

## Prodigy Infotech Cybersecurity Internship

This project was developed as **Task-01** during my Cybersecurity Internship at **Prodigy Infotech**.

## Project Description

A Python program that implements the **Caesar Cipher** algorithm to encrypt and decrypt text messages.

The program allows the user to enter a message, specify a shift value, and choose whether to encrypt or decrypt the message.

## Features

- Encrypt text messages
- Decrypt encrypted messages
- User-defined shift value
- Supports uppercase and lowercase letters
- Preserves spaces, numbers, and special characters
- Simple command-line interface

## Technologies Used

- Python

## How Caesar Cipher Works

The Caesar Cipher is a classical substitution cipher where each letter in a message is shifted by a fixed number of positions in the alphabet.
