# Caesar Cipher in Python 🔐

**A project completed for the Cyber Security Internship at [Prodigy InfoTech](https://prodigyinfotech.dev/).**

## 📝 Project Overview
This project was developed as **Task 01** during my Cybersecurity Internship at Prodigy InfoTech. It is a Python program that implements the **Caesar Cipher** algorithm to encrypt and decrypt text messages. The program allows the user to enter a message, specify a shift value, and choose whether to encrypt or decrypt the message.

## ✨ Features
- **Encrypt & Decrypt:** Encrypt text messages and decrypt them back.
- **Custom Shift Value:** User-defined shift value for the cipher.
- **Case Support:** Supports uppercase and lowercase letters.
- **Character Preservation:** Preserves spaces, numbers, and special characters.
- **Simple CLI:** Simple command-line interface.

## 🛠️ Prerequisites
This script runs on basic Python. No external libraries or installations are required.

## 🔍 How Caesar Cipher Works
The Caesar Cipher is a classical substitution cipher where each letter in a message is shifted by a fixed number of positions in the alphabet.

For example, with a shift value of `3`:

```text
A → D
B → E
C → F
...
X → A
Y → B
Z → C
```

## 🚀 Usage
1. Download or clone the repository to your local machine.
2. Run the Python script in your terminal or IDE:
   ```bash
   python caesar_cipher.py
   ```
3. Enter your message, choose a shift value, and select encrypt or decrypt.
4. Read the terminal output to see your result!
